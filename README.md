# efood · Catálogo e navegação

Projeto em React com Styled Components e React Router. A página inicial exibe os restaurantes e cada card abre o cardápio correspondente. Nesta etapa, o catálogo usa uma cópia dos dados públicos da EBAC.

```sh
npm ci
npm run dev
npm run build
```

O [arquivo de referência no Figma](https://www.figma.com/file/JjduV2Tg7I3TzYUUsees8b/efood) foi reproduzido a partir das capturas fornecidas. As fotos são da [API do curso](https://api-ebac.vercel.app/api/efood/restaurantes).
